# Code of Conduct

Atom follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainer through GitHub (the repository's **Security** tab → **Report a vulnerability** also reaches the maintainer privately). Reports are handled confidentially; the maintainer may edit or remove content and block contributors who break this code.
